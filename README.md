# Signal — 맥 전용 KOL 콘텐츠 데스크

관리 계정: GGzy55, gat_only_you, seyyxz. Python 3.10 이상, 로컬 앱은 추가 패키지 필요 없음.

## 한 번 설치하고 계속 사용하기

1. 폴더를 맥의 고정 위치에 보관합니다. 예: ~/twitter-dashboard. 설치 후 폴더를 이동하지 마세요.
2. 터미널에서 해당 폴더로 이동하고 `python3 install_mac.py`를 실행합니다. 또는 설치.command를 실행합니다.
3. 키체인 비밀번호 입력 프롬프트에 재발급한 TwitterAPI.io 키를 입력합니다. 키를 채팅이나 코드에 넣지 않습니다.
4. 맥 키체인의 첫 접근 허용창이 뜨면 본인이 설치한 프로그램인지 확인하고 허용합니다.
5. 브라우저에서 http://127.0.0.1:8000 을 열고 즐겨찾기합니다.

설치 도구는 사용자 LaunchAgent를 만들고 현재 로그인 세션에서 서버를 시작합니다. 관리자 권한은 필요 없습니다. 자동으로 연 브라우저에서 첫 접속이 실패하면 서버 준비 후 새로고침하세요. 이미 포트 8000에서 수동 서버가 실행 중이면 먼저 해당 터미널에서 Ctrl+C로 종료하세요.

맥이 켜져 있고 로그인된 동안 계속 접속할 수 있습니다. 매일 09:00, 15:00, 21:00 KST에 수집하며, 최초 실행과 잠자기 후 현재 슬롯이 아직 수집되지 않았으면 한 번 갱신합니다. 잠자기 중이나 전원이 꺼져 있을 때는 수집하지 않습니다. 놓친 슬롯 전체를 재실행하지 않습니다. 페이지 접속/새로고침은 제공사 API를 호출하지 않고 저장된 데이터만 읽습니다. 페이지는 60초마다 로컬 데이터를 다시 읽습니다.

키는 맥 키체인의 SignalTwitterAPI 항목에 저장됩니다. 환경변수 TWITTERAPI_IO_KEY가 이미 있으면 그것을 우선 사용합니다. 로그인 자동 실행은 터미널 환경변수를 상속하지 않으므로 키체인 등록이 필요합니다. LaunchAgent 파일에 API 키가 들어가지 않습니다.

## 화면

- 오늘의 콘텐츠: 계정 카드, 관측한 소재, 규칙 기반 초안과 게시 기록 작성
- 최신 화제·피드: 한국어 크립토/일상/AI 정보 검색과 작은 계정 탐색의 최신 글, 원문과 시각
- 성과 시각화: 실제 팔로워 관측 추이, 최근 글 좋아요/답글/리포스트 비교, 직접 기록한 카테고리 비율
- 게시 기록과 운영 설정

최신 화제는 작성자 팔로워 1,000명 이상 AND 게시글 조회수 3,000회 이상인 글만 표시합니다. 정보가 없으면 제외하고, 후보/기준미달/지표미확인 건수를 표시합니다. 내 관리 계정의 최근 글과 성과에는 이 필터를 적용하지 않습니다.

화제 탐색은 최근 7일 Top 검색을 사용합니다. 좋아요 10개 이상의 후보를 우선 조회하며, 조건 통과 글이 없으면 좋아요 제한 없는 검색을 한 번 추가합니다. 최종 통과 기준은 팔로워와 조회수 두 가지입니다. 추가 조회도 월 900회 상한에 포함되므로 실패/기준미달이 잦으면 월말 수집이 중단될 수 있습니다.

최신 화제는 제한된 검색 표본이며 X 전체 트렌드 순위가 아닙니다. 주제 카드의 수치는 표본 내 등장 건수입니다. 검색어에 의해 편향된 표본이므로 상승률이나 시장 전체 빈도를 의미하지 않습니다. 차트 데이터가 충분하지 않으면 빈 상태를 표시합니다. 추천 시간과 문구는 초기 운영 템플릿이며 AI 또는 성과 기반 추천이 아닙니다. 셀카/일상은 실제 사진·경험으로 완성하세요.

## 비용과 저장

월 API 요청 최대 900회. 실패 요청도 포함합니다. 프로필은 하루 한 번, 최근 글과 검색은 수집 슬롯마다 조회합니다. 30일 정상 운영 시 약 660회 요청 (추가 검색도 월 900회 상한 안에서 실행). 반환량/단가에 따른 실제 비용은 제공사에서 확인하고 자동 충전은 별도로 관리하세요. 요청 상한이 원화 비용 상한을 보장하지 않습니다.

SQLite와 원문 캐시는 data/dashboard.sqlite에 보관됩니다. 기존 게시 기록은 유지합니다. API 실패 시 이전 데이터와 오류를 보여줍니다. 기록/원문 보관 기간과 제공사 약관 범위는 실제 운영에 맞춰 관리해야 합니다.

서버는 127.0.0.1에만 바인딩합니다. 휴대폰 또는 외부 접속을 위한 공개 서버가 아닙니다.

## 수동 실행 / 검증

```sh
python3 server.py
python3 -m unittest discover -s tests -v
```

`python3 server.py --refresh-once`는 즉시 조회를 강제하며 API 비용을 발생시킵니다. 웹 화면에는 강제 수집 버튼이 없습니다.

로그는 ~/Library/Logs/SignalDashboard/에 있습니다.
자동 실행을 중지하려면:

```sh
launchctl bootout gui/$(id -u)/com.signal.kol-dashboard
```

자동 실행 등록을 삭제하려면 이후 ~/Library/LaunchAgents/com.signal.kol-dashboard.plist를 Finder에서 제거합니다. 앱 데이터와 키체인 키는 별도 보관되며 자동 삭제되지 않습니다.

## 보류된 웹 배포

Cloudflare Workers 구성은 선택 옵션으로 남아 있습니다. 현재 기본 워크플로는 맥 로컬 버전이며 가입/유료 서비스는 필요 없습니다. Workers 전용 UI와 로컬 UI는 별개입니다. 자세한 웹 배포 지침은 DEPLOY.md에 있습니다.

성장 참고 요소는 텍스트 규칙으로 질문, 경험 표현, 학습 구조, 줄바꿈을 설명합니다. 실제 성장 효과를 예측하지 않습니다. 5,000뷰 이상은 별도 표시하며, 참고 주제에 내 경험·관점을 더하는 초안을 제공합니다. 비크립토 테마도 검색하지만 계정별 페르소나 적합도는 아직 계산하지 않습니다.

## 성장 연구

테마는 크립토·일상·AI 정보글로 제한합니다. 연예인·아이돌·배우 관련 키워드를 검색에서 제외하고, 저장된 후보도 규칙으로 재검사합니다. 기존 culture 검색 캐시는 표시하지 않습니다. 규칙에 없는 이름/은어는 누락될 수 있고 정확한 문맥 판정은 아닙니다.

성장 연구 탭에는 팔로워 100~999명/조회 300회 이상인 별도 사례를 보여줍니다. 평소 대비 상승이나 실제 성장 효과는 검증하지 않았습니다. 작은 계정 탐색은 하루 한 번, 기존 월 요청 상한 안에서 실행합니다. 질문 소재는 원글의 질문 표현을 수집한 것으로 답글 분석과 구분합니다.

게시 기록을 먼저 저장한 뒤 24h/72h 조회, 답글, 프로필 방문, 글에 귀속되는 팔로우 수를 직접 입력할 수 있습니다. 미확인 지표는 빈칸으로 보존하고 0으로 바꾸지 않습니다. 계정 전체 팔로워 증가를 글별 전환으로 입력하지 마세요. 원문과 방문 권한이 없는 지표는 자동 조회하지 않습니다. 기존 게시 기록/키체인/SQLite는 삭제하지 않고 새 테이블을 추가합니다.

## 글 상세 데이터와 화면

원문 카드의 '첫 문장 · 포맷 · 관측 기록'을 펼치면 게시글 ID, 원문 링크, 게시/수집 시각, 수집 시점 팔로워 수, 첫 문장, 콘텐츠 포맷, 후킹 후보와 분류 근거를 확인할 수 있습니다. 콘텐츠 포맷과 후킹 유형은 별도 필드입니다. 미디어가 제공되면 사진/영상 포맷으로 분류하고, 스레드는 별도 확인 없이 단정하지 않습니다.

추가 API 호출 없이 예약 검색에서 다시 발견한 글의 조회/좋아요/답글/리포스트 관측값을 SQLite post_observations 테이블에 누적합니다. 최초 도입 시 기존 검색 캐시의 원래 수집 시각으로 1회 관측을 보존합니다. 수치 미확인은 NULL로 유지합니다. 검색 표본이라 다시 나타나지 않은 글의 수치는 갱신되지 않습니다. 작성자 평소 성과/성장 효과는 아직 계산하지 않습니다.

밝은 배경과 어두운 사이드바, 테마별 포인트 색, 접히는 분석 패널로 화면을 재구성했습니다. 모션은 prefers-reduced-motion 설정을 존중합니다. 사용자 제공 awesome-opus5-5-videos의 README/모션 그래픽 프롬프트를 디자인 방향 참고로 검토했으며 라이브러리나 코드를 가져오지 않았습니다.

## 소재 보관함

수집 피드/성장 참고 카드에서 소재로 저장하면 원문 스냅샷과 근거 링크를 계정별로 보관합니다. 각도, 초안, 필요한 자료, 테마, 준비 상태와 게시 예정 시각(KST)을 편집할 수 있습니다. 같은 글을 같은 계정에 중복 저장하지 않고 기존 소재를 엽니다. 여러 계정에 같은 소재가 있으면 각도와 시간을 확인하도록 표시합니다.

게시 준비 상태에는 각도와 초안이 필요합니다. 첫 화면에는 선택한 계정의 준비된 초안 최대 3개를 보여줍니다. 이는 자동 게시 예약이 아닙니다. 직접 게시한 해당 계정의 X 링크를 입력하고 게시 완료로 저장하면 기존 records에 한 번 연결합니다. 완료 후 편집을 잠가 게시 당시 초안을 보존합니다. 원문이 피드에서 사라져도 보관한 원문은 남고, 다른 화면에서 수정된 항목은 덮어쓰기 대신 충돌을 알립니다. 보관함은 기존 SQLite에 materials 테이블로 추가하며 기존 게시 기록과 키는 유지합니다.

별도 게시 기록 메뉴는 제거했습니다. 게시 완료 관리는 소재 보관함으로 통합하며, 기존 records 데이터와 성장 실험 연결은 보존합니다.

계정 페르소나는 확인된 핸들 연결로 저장됩니다: GGzy55=gg(입문·일상·셀카·밋업), gat_only_you=유경(크립토 전반 이슈·프로젝트/생태계·규제/보안·뉴스/시장·에어드랍·밋업), seyyxz=세인(실제 트레이딩·시장/경제 시황·뉴스·일상·밋업). 크립토 지식 수준은 초보로 두되 세인은 실제 트레이딩 채널로 반영합니다. 관심 테마/표현에 따라 참고 글을 정렬하고 계정별 초안 템플릿을 제공합니다. 규칙 정렬은 성장 효과나 성과 기반 예측이 아닙니다. 실제 경험이 없는 부분은 직접 확인해 완성해야 합니다.

세인의 소재에는 금리·환율·FOMC·CPI 등 거시경제 키워드를 포함합니다. 거래 기록은 본인이 실행한 사실만 작성하고, 수치의 원출처·발표 시각과 개인 전망을 구분합니다.

팬 투표/응원 게시물도 제외합니다: MAMAVOTE, MAMA 팬스 초이스, #idle 등 아이돌 해시태그와 팬덤 투표/스밍 표현. 일반 DAO 투표나 아이들과 보낸 일상은 일괄 차단하지 않습니다. 기존 검색 캐시에도 표시 시 필터를 적용합니다.

AI 테마는 영상·릴스·쇼츠·블로그·인스타·콘텐츠·부업 실험으로 좁혔습니다. AI 추천에는 직접 사용/제작, 실행 단계, 시간/비용, 한계의 텍스트 단서를 우선 반영하고 수익 보장/강의·제휴 표현을 검토 표시합니다. 이는 작업물이나 수익을 검증한 결과가 아닙니다. 계정별 AI 활용 각도를 별도로 제공합니다. 일반 AI 모델 뉴스는 AI 소재 피드에서 제외합니다.

## 수집 아카이브

테마에 맞는 수집 글의 원문·작성자·원문 링크·마지막 반환 수치와 최초/마지막 관측 시각을 post_archive에 보관합니다. 반복 수집은 같은 ID를 업데이트하며 최신 피드에서 사라져도 아카이브는 남습니다. 원문이나 수치가 바뀌면 마지막 관측 값을 표시하고 별도 수치 이력은 유지합니다. 연예인/팬덤 및 현재 범위 밖의 글은 제외 규칙을 적용합니다.

시작 시 현재 검색·관리 계정 글 캐시와 소재 보관함의 원문을 아카이브로 옮깁니다. 이미 캐시에서 덮어써진 과거 원문은 복원할 수 없습니다. 이후 수집은 자동 누적하며 기간 만료 삭제는 하지 않습니다. data 폴더는 유지하고 백업하세요. 아카이브 검색/테마 필터/20개 단위 페이지 조회는 추가 API 비용 없이 로컬 자료만 읽습니다. 기준 미달 후보도 보관될 수 있으므로 최신 확산 피드와 건수가 다를 수 있습니다. 오래된 글도 아카이브에서 소재로 저장할 수 있습니다. X에서 삭제된 원문은 링크가 작동하지 않을 수 있으며 데이터 제공사의 보관/삭제 의무는 별도로 따라야 합니다.
