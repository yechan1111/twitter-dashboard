# Signal — 맥 전용 KOL 콘텐츠 데스크

관리 계정: GGzy55, gat_only_you, seyyxz. Python 3.10 이상, 로컬 앱은 추가 패키지 필요 없음.

## 한 번 설치하고 계속 사용하기

1. 폴더를 맥의 고정 위치에 보관합니다. 예: ~/twitter-dashboard. 설치 후 폴더를 이동하지 마세요.
2. 터미널에서 해당 폴더로 이동하고 `python3 install_mac.py`를 실행합니다. 또는 설치.command를 실행합니다.
3. 키체인 비밀번호 입력 프롬프트에 재발급한 TwitterAPI.io 키를 입력합니다. 키를 채팅이나 코드에 넣지 않습니다.
4. 맥 키체인의 첫 접근 허용창이 뜨면 본인이 설치한 프로그램인지 확인하고 허용합니다.
5. 브라우저에서 http://127.0.0.1:8000 을 열고 즐겨찾기합니다.

설치 도구는 사용자 LaunchAgent를 만들고 현재 로그인 세션에서 서버를 시작합니다. 관리자 권한은 필요 없습니다. 자동으로 연 브라우저에서 첫 접속이 실패하면 서버 준비 후 새로고침하세요. 이미 포트 8000에서 수동 서버가 실행 중이면 먼저 해당 터미널에서 Ctrl+C로 종료하세요.

맥이 켜져 있고 로그인된 동안 계속 접속할 수 있습니다. 매일 09:00, 15:00, 21:00 KST에 수집하며, 최초 실행과 잠자기 후 현재 슬롯이 아직 수집되지 않았으면 한 번 갱신합니다. 잠자기 중이나 전원이 꺼져 있을 때는 수집하지 않습니다. 놓친 슬롯 전체를 재실행하지 않습니다. 페이지 접속/새로고침은 제공사 API를 호출하지 않고 저장된 데이터만 읽습니다. 페이지는 60초마다 로컬 데이터를 다시 읽습니다.

키는 맥 키체인의 SignalTwitterAPI 항목에 저장됩니다. 환경변수 TWITTERAPI_IO_KEY가 이미 있으면 그것을 우선 사용합니다. 로그인 자동 실행은 터미널 환경변수를 상속하지 않으므로 키체인 등록이 필요합니다. LaunchAgent 파일에 API 키가 들어가지 않습니다.

## 화면

- 오늘의 콘텐츠: 계정 카드, 관측한 소재, 규칙 기반 초안과 게시 기록 작성
- 최신 화제·피드: 한국어 크립토/일상/공부/셀카 검색 세 개의 최신 글, 원문과 시각
- 성과 시각화: 실제 팔로워 관측 추이, 최근 글 좋아요/답글/리포스트 비교, 직접 기록한 카테고리 비율
- 게시 기록과 운영 설정

최신 화제는 작성자 팔로워 1,000명 이상 AND 게시글 조회수 3,000회 이상인 글만 표시합니다. 정보가 없으면 제외하고, 후보/기준미달/지표미확인 건수를 표시합니다. 내 관리 계정의 최근 글과 성과에는 이 필터를 적용하지 않습니다.

화제 탐색은 최근 7일 Top 검색을 사용합니다. 좋아요 10개 이상의 후보를 우선 조회하며, 조건 통과 글이 없으면 좋아요 제한 없는 검색을 한 번 추가합니다. 최종 통과 기준은 팔로워와 조회수 두 가지입니다. 추가 조회도 월 900회 상한에 포함되므로 실패/기준미달이 잦으면 월말 수집이 중단될 수 있습니다.

최신 화제는 제한된 검색 표본이며 X 전체 트렌드 순위가 아닙니다. 주제 카드의 수치는 표본 내 등장 건수입니다. 검색어에 의해 편향된 표본이므로 상승률이나 시장 전체 빈도를 의미하지 않습니다. 차트 데이터가 충분하지 않으면 빈 상태를 표시합니다. 추천 시간과 문구는 초기 운영 템플릿이며 AI 또는 성과 기반 추천이 아닙니다. 셀카/일상은 실제 사진·경험으로 완성하세요.

## 비용과 저장

월 API 요청 최대 900회. 실패 요청도 포함합니다. 프로필은 하루 한 번, 최근 글과 검색은 수집 슬롯마다 조회합니다. 30일 정상 운영 시 약 630회 요청 (추가 검색 시 최대 900회). 반환량/단가에 따른 실제 비용은 제공사에서 확인하고 자동 충전은 별도로 관리하세요. 요청 상한이 원화 비용 상한을 보장하지 않습니다.

SQLite와 원문 캐시는 data/dashboard.sqlite에 보관됩니다. 기존 게시 기록은 유지합니다. API 실패 시 이전 데이터와 오류를 보여줍니다. 기록/원문 보관 기간과 제공사 약관 범위는 실제 운영에 맞춰 관리해야 합니다.

서버는 127.0.0.1에만 바인딩합니다. 휴대폰 또는 외부 접속을 위한 공개 서버가 아닙니다.

## 수동 실행 / 검증

```sh
python3 server.py
python3 -m unittest discover -s tests -v
```

`python3 server.py --refresh-once`는 즉시 조회를 강제하며 API 비용을 발생시킵니다. 웹 화면에는 강제 수집 버튼이 없습니다.

로그는 ~/Library/Logs/SignalDashboard/에 있습니다.
자동 실행을 중지하려면:

```sh
launchctl bootout gui/$(id -u)/com.signal.kol-dashboard
```

자동 실행 등록을 삭제하려면 이후 ~/Library/LaunchAgents/com.signal.kol-dashboard.plist를 Finder에서 제거합니다. 앱 데이터와 키체인 키는 별도 보관되며 자동 삭제되지 않습니다.

## 보류된 웹 배포

Cloudflare Workers 구성은 선택 옵션으로 남아 있습니다. 현재 기본 워크플로는 맥 로컬 버전이며 가입/유료 서비스는 필요 없습니다. Workers 전용 UI와 로컬 UI는 별개입니다. 자세한 웹 배포 지침은 DEPLOY.md에 있습니다.

성장 참고 요소는 텍스트 규칙으로 질문, 경험 표현, 학습 구조, 줄바꿈을 설명합니다. 실제 성장 효과를 예측하지 않습니다. 5,000뷰 이상은 별도 표시하며, 참고 주제에 내 경험·관점을 더하는 초안을 제공합니다. 비크립토 테마도 검색하지만 계정별 페르소나 적합도는 아직 계산하지 않습니다.
