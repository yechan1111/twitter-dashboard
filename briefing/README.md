# X 브리핑 검증 모듈 (1차)

기존 Python 로컬 대시보드, SQLite, Cloudflare Worker, 수집 스케줄은 수정하지 않습니다.

- `verify_post(post)`: 개별 X status URL, 게시글 ID, 작성일, 반응 수치를 확인합니다. 누락 수치는 `None`으로 유지합니다.
- `rank_post(post, followers)`: 댓글 30+/100+ 및 팔로워 대비 조회수에 가산점을 주는 탐색용 점수입니다.
- `select_candidates(posts)`: 중복 원문을 제거하고 검증 가능한 후보를 정렬합니다.

**주의:** URL 형식과 입력 데이터의 일관성 검사일 뿐, X 서버에서 실제 게시물의 존재나 수치를 검증한 것은 아닙니다. '10만 뷰' 표시 전에는 신뢰 가능한 제공사 응답으로 원문 ID와 지표를 대조해야 합니다. 출처·수집 시각·API 응답 기록을 추가하는 것이 다음 단계입니다. 이 모듈은 자동 게시하지 않습니다.

테스트: `python3 -m unittest tests/test_briefing.py -v`

다음 단계: 기존 SQLite 아카이브의 정규화 필드 매핑, 출처/관측 시각 기록, 유경 5+3/세인 5+3/GG 3개 편집 큐, API 예산 보호, 화면 통합 및 자동 브리핑 연동. 비밀키는 코드나 Git에 저장하지 않습니다.
